🛍️ Black Friday Sales Analysis (EDA)

This project analyzes the **Black Friday Sales dataset** to understand customer purchase behavior and spending trends.

Key Steps
- Performed data cleaning and preprocessing  
- Conducted univariate and bivariate analysis  
- Visualized relationships between customer demographics and purchase amount  

Tools Used
- Python, Pandas, NumPy, Matplotlib, Seaborn  

Key Insights
- Age group 26–35 has the highest purchase amount  
- Males spend slightly more on average  
- Product Category 1 is the most popular
